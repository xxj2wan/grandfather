# grandfather

할아버지를 위한 두뇌 훈련 안드로이드 앱 — **같은 숫자 짝 찾기**

## 게임 규칙
- 4×4 판에 1~60 사이 숫자 16개가 무작위로 나옵니다.
- 그중 **3쌍**만 같은 숫자이고, 나머지는 모두 다른 숫자입니다.
- 제한 시간 **60초** 안에 같은 숫자 두 칸을 차례로 눌러 쌍을 찾습니다.
  - 맞으면 초록색, 틀리면 잠깐 빨간색으로 표시됩니다.
  - 시간이 다 되면 못 찾은 쌍을 노란색으로 보여줍니다.
- 매 문제마다 새로 무작위 배치됩니다. (서버/DB 없음)

## 어르신 배려
- 시스템 글꼴 크기 설정과 관계없이 숫자가 칸에 꽉 차게 표시 (dp 고정)
- 큰 버튼, 고대비 색상, 세로 화면 고정
- 게임 중 화면 꺼짐 방지, 쌍을 찾으면 진동

## 기술 스택
Kotlin · Jetpack Compose · minSdk 26 (Android 8.0) · targetSdk 35
